# SvelteKit & UnoCSS & TypeScript & STDF

This template should help get you started developing with SvelteKit & UnoCSS & TypeScript & STDF.

## Recommended IDE Setup

- [VS Code](https://code.visualstudio.com/) + [Svelte](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode) + [UnoCSS](https://unocss.dev) + [TypeScript](https://typescriptlang.org) + [STDF](https://stdf.dev) .

- [WebStorm](https://www.jetbrains.com/webstorm/) + [Svelte](https://www.jetbrains.com/help/webstorm/svelte.html) + [UnoCSS](https://unocss.dev) + [TypeScript](https://typescriptlang.org) + [STDF](https://stdf.dev) .

## Install and run project

```bash
npm i

npm run dev
```
