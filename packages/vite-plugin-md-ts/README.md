# @any-tdf/vite-plugin-md-ts

[简体中文](./README_CN.md)

A Vite and Rollup plugin that transforms Markdown files into JavaScript modules exporting either the original Markdown or an HTML string generated by [marked](https://marked.js.org/).

## Install

```sh
bun add @any-tdf/vite-plugin-md-ts -D
```

## Usage

```ts
import { defineConfig } from 'vite';
import md from '@any-tdf/vite-plugin-md-ts';

export default defineConfig({
	plugins: [
		md({
			include: ['src/**/*.md'],
			exclude: ['src/private/**'],
			marked: {}
		})
	]
});
```

Markdown files can then be imported as strings:

```ts
import guide from './guide.md';
```

When `marked` options are provided, the default export contains HTML. When they are omitted, the original Markdown source is exported.

## Options

| Option    | Type            | Default       | Description                                                           |
| --------- | --------------- | ------------- | --------------------------------------------------------------------- |
| `include` | `string[]`      | `['**/*.md']` | Glob patterns included by the plugin.                                 |
| `exclude` | `string[]`      | `undefined`   | Glob patterns excluded by the plugin.                                 |
| `marked`  | `MarkedOptions` | `undefined`   | Enables Markdown-to-HTML conversion with the provided marked options. |

The plugin preserves Vite query parameters while filtering by the underlying `.md` filepath. It can also be used in a Rollup configuration.
