# STDF Internationalization

STDF components use Svelte Context for locale text. The default locale is Simplified Chinese.

## Configure Locale

Set `STDF_lang` near the application root, such as `App.svelte` or `+layout.svelte`:

```svelte
<script lang="ts">
	import { setContext } from 'svelte';
	import { en_US } from 'stdf/lang';

	setContext('STDF_lang', en_US);
</script>
```

All descendant STDF components can read this context with `getContext('STDF_lang')`.

## Important Behavior

Context switching is not reactive by itself. If the app needs runtime language switching, design the app-level state and remounting or context boundaries deliberately. Do not assume existing STDF components will update every text node from a changed Context value.

## Locale Presets

Locale presets are exported from `stdf/lang`.

When configuring an application:

- Import an existing preset from `stdf/lang` when it fits the project.
- Create an app-local locale object when the product needs custom wording.
- Keep locale keys consistent with an existing preset shape.

## Current Locale Coverage

STDF includes many locale presets, including `en_US`, `zh_CN`, `zh_TW`, `ja_JP`, `ko_KR`, `es_ES`, `fr_FR`, `de_DE`, `it_IT`, `ru_RU`, and others. Inspect the installed `stdf/lang` package exports for the exact current list.
