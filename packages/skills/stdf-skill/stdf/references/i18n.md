# STDF Internationalization

STDF exposes `ConfigProvider` with `locale` (default `zh_CN`), `builtInIconLibrary` (default `remix`), and the `children` snippet. It does not expose the React/Vue provider's `theme`, `mode`, `iconPath`, or `syncTheme` props.

It sets `STDF_lang` at initialization. Existing ordinary components do not react to replacing that context value; remount the locale boundary with a keyed block for runtime language changes. Legacy `setContext('STDF_lang', locale)` remains supported. The provider also updates the global functional-feedback locale; a local context at the call site does not isolate feedback.

Mount exactly one `Feedback` container at the application root. `ConfigProvider` does not replace it.

Read [the internationalization guide](guides/internation.md) for framework-specific configuration and all 66 locale exports, and [functional feedback](guides/feedback.md) for initialization and imperative APIs. Locale objects must satisfy the installed `stdf/lang` `LangProps` type.
