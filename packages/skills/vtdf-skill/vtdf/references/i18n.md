# VTDF Internationalization

VTDF exposes `ConfigProvider` with `locale` (default `zh_CN`), `theme` (`ANYTDF`), `mode` (`primary`), `iconPath` (fonts/symbol.svg), `builtInIconLibrary` (`remix`), and `syncTheme` (`true`). Content uses the default Vue slot.

Locale changes are reactive for ordinary descendant components. A nested provider with `:sync-theme="false"` avoids resetting the global theme and mode when only scoping locale. Functional feedback still uses global state. The mounted `Feedback` component writes the global feedback locale from its injected provider; a different provider at the call site does not select its locale.

Mount exactly one `Feedback` container at the application root. `ConfigProvider` does not replace it.

Read [the internationalization guide](guides/internation.md) for framework-specific configuration and all 66 locale exports, and [functional feedback](guides/feedback.md) for initialization and imperative APIs. Locale objects must satisfy the installed `vtdf/lang` `LangProps` type.
