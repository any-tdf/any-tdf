# VTDF Internationalization

VTDF components use `ConfigProvider` for locale text. The default locale is Simplified Chinese.

## Configure Locale

Wrap the application root or a subtree with `ConfigProvider`:

```vue
<script setup lang="ts">
import { ConfigProvider } from 'vtdf';
import { en_US } from 'vtdf/lang';
</script>

<template>
	<ConfigProvider :locale="en_US">
		<RouterView />
	</ConfigProvider>
</template>
```

All descendant VTDF components read the current locale. For scoped wording, wrap a subtree with another `ConfigProvider`.

## ConfigProvider Props

| Name | Type | Meaning |
| -------------------- | -------------------- | ------------------------------------------------- | ------------------------- |
| `locale` | `LangProps` | Component internationalization text config |
| `theme` | `SwitchThemeInput` | Theme config, applied through VTDF theme helpers |
| `mode` | `'primary' \\        | 'dark'` | Light or dark mode config |
| `iconPath` | `string` | Global SVG symbol path used by `Icon` |
| `builtInIconLibrary` | `BuiltInIconLibrary` | Built-in SVG icon library used by VTDF components |

## Locale Presets

Locale presets are exported from `vtdf/lang`.

When configuring an application:

- Import an existing preset from `vtdf/lang` when it fits the project.
- Create an app-local locale object when the product needs custom wording.
- Keep locale keys consistent with an existing preset shape.

## Current Locale Coverage

VTDF includes many locale presets, including `en_US`, `zh_CN`, `zh_TW`, `ja_JP`, `ko_KR`, `es_ES`, `fr_FR`, `de_DE`, `it_IT`, `ru_RU`, and others. Inspect the installed `vtdf/lang` package exports for the exact current list.
