# RTDF Internationalization

RTDF exposes `ConfigProvider` with `locale` (default `zh_CN`), `theme` (`ANYTDF`), `mode` (`primary`), `iconPath` (unset; Icon uses fonts/symbol.svg), `builtInIconLibrary` (`remix`), and `syncTheme` (`true`). Content uses React children.

Locale changes are reactive for ordinary descendant components. A nested provider with `syncTheme={false}` avoids resetting the global theme and mode when only scoping locale. Functional feedback still uses global state. Each mounted provider writes the global feedback locale, so nested providers do not isolate feedback calls.

Mount exactly one `Feedback` container at the application root. `ConfigProvider` does not replace it.

Read [the internationalization guide](guides/internation.md) for framework-specific configuration and all 66 locale exports, and [functional feedback](guides/feedback.md) for initialization and imperative APIs. Locale objects must satisfy the installed `rtdf/lang` `LangProps` type.
