# VTDF

基于 Vue 与 Tailwind CSS 的移动端组件库。

Mobile component library based on Vue and Tailwind CSS.

## 安装

```sh
bun add vtdf@0.0.1-alpha.0
```

## 使用

```vue
<script setup lang="ts">
import { Button } from 'vtdf';
</script>

<template>
	<Button>VTDF</Button>
</template>
```

组件、主题、多语言、类型和工具方法均由 `vtdf` 包提供。完整文档请访问 [vtdf.dev](https://vtdf.dev)。
