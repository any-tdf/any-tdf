# STDF

基于 Svelte 与 Tailwind CSS 的移动端组件库。

Mobile component library based on Svelte and Tailwind CSS.

## 安装

```sh
bun add stdf@3.0.0-alpha.0
```

## 使用

```svelte
<script lang="ts">
	import { Button } from 'stdf';
</script>

<Button>STDF</Button>
```

组件、主题、多语言、类型和工具方法均由 `stdf` 包提供。完整文档请访问 [stdf.dev](https://stdf.dev)。
