# Change Log

## 1.0.1

- Updated the extension icon and Marketplace metadata to use the Any TDF brand.
- Linked the Any TDF homepage, Monorepo, issue tracker, and discussions.

## 1.0.0

- Rebranded STDF for VS Code as Any TDF for VS Code while preserving the existing Marketplace identifier and automatic update path.
- Added hover documentation and code completion for STDF, RTDF, and VTDF.
- Added nearest-package detection for Monorepos and nested packages.
- Added bundled Chinese and English component API documentation.
- Added framework-specific property, event, child-content, snippet, and Vue slot completions.
- Added `AnyTDF.English` and retained `STDF.English` as a deprecated compatibility setting.

## 0.0.36 and earlier

- Previous releases provided STDF component documentation and development assistance under the STDF for VS Code name.
